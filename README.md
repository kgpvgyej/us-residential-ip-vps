## 先解决一个前置问题：双 ISP 这个标签怎么验

市面上所有卖住宅 IP 的商家都在标题里写“双 ISP”，但双 ISP 不是一个营销词，它有两个可以查的技术维度，**必须同时成立**：

1. **Company 类型显示 ISP**（IP 注册信息里的所属机构是宽带运营商，不是 hosting/cloud）；
2. **ASN 类型显示 ISP**（这个 IP 所在自治域的性质是 ISP，不是数据中心）。

只满足其中一条的，大概率是广播段伪装——商家从机房买一段 IP，把注册信息改成某个运营商的名字，Company 那栏能骗过去，但 ASN 那栏骗不过去。这种段子在 TikTok、亚马逊后台这类风控严的地方，挂上去前几天可能没事，一旦触发复审就整段连坐。

判断方法不复杂，也不需要什么技术背景：

- 拿商家给的测试 IP，丢进 ipinfo.io 看 org 和 ASN 两栏，再丢进 Scamalytics 看欺诈评分；
- 换两三个不同的检测工具交叉，只看一家容易被针对；
- 问商家这批 IP 是怎么来的。自己拉当地宽带组网的，和从上游批量买广播段的，说法完全不同；
- 最后一步永远是实测：拿你要跑的那个业务去试，平台认不认，只有平台说了算。

这也是为什么下面所有推荐都建议先月付、或者先用年付特价版试一个月——48 小时退款窗口内发现问题，成本几乎为零。

## 哪些人不该买，以及退款规则要看清

先说退款，因为这是最容易吃亏的地方，三条产品线规则完全不同：

- **9929 / 4837 / 纽约芝加哥等常规线**：48 小时内不满意无条件退款，自动开通、即时交付。
- **家宽 VDS**：标注为特殊产品，**只退网站余额**，不原路退回。下单前想清楚，这笔钱退回来也只能继续在站内消费。
- **CN2 GIA 共享 NAT**：**无退款**，OpenVZ 虚拟化，手动开通，24 小时内交付。

另外官方的退款条款里还有一条：48 小时内如果带宽超分配 5% 或 20GB（取较小值），属于“大量使用”，不在全额退款范围内。试 IP 的时候别一上来就跑满带宽压测。

再说谁不适合：

**想跑大流量视频站、镜像站、下载站的，别买。** 这条线带宽 20–100Mbps，价格还比普通机房 VPS 贵，用住宅 IP 跑流量业务是双重浪费——你付了 IP 的溢价，却没用到 IP 的价值。

**需要 Windows 且着急用的，预留时间。** 丽萨主机装 Windows 要提交工单走人工流程，不是后台一键重装。当天要交付的，把这个环节算进计划。

**移动宽带用户，先想好线路。** 第三方实测里丽萨主机的移动延迟 232ms，比电信高 50ms 左右。移动用户如果想稳，要么接受这个数字，要么考虑三网延迟更平均的商家。

**预算卡在 20 元/月以下的，这里没有你的选项。** 住宅 IP 本身有成本，丽萨主机最低就是 68 元月付 / 399 元年付。再往下只能选非住宅的普通 VPS，那就回到机房 IP 被风控的老问题上了。

## 常见问题

**双 ISP 到底怎么自己验？**
拿商家提供的测试 IP（丽萨主机支持工单索要），在 ipinfo.io 上看 org 和 ASN 两栏，两栏都指向 ISP 才算过关；再用 Scamalytics 看欺诈评分，0 分最好，超过 50 基本别用。换两三个工具交叉，别只信一家。纽约的 154.49 段是目前公开可查的 0 分干净段。

**家宽 VDS 和双 ISP 住宅 IP VPS 有什么区别？**
前者是服务器真的放在美国民房里，走当地宽带运营商的线；后者是机房里的机器，配了一段注册信息为 ISP 的住宅 IP。VDS 的 IP 真实性高一档，代价是带宽小、价格贵一倍、延迟也没优势。做高价值账号选 VDS，跑量选住宅 IP VPS。

**到手第一件事做什么？**
验 IP。ipinfo.io 看归属，Scamalytics 看评分，再用你要跑的业务实际登录一次。48 小时退款窗口就是给你干这个的。发现 IP 有问题，24 小时内工单申请更换是免费的，超时可能要收费。

**电信、联通、移动分别怎么选线？**
电信优先 9929，精品网 + CMIN2 回程对电信最友好；联通 9929 和 4837 都行，9929 更稳；移动三网表现相对弱一些，如果移动是主力线路，重点看商家的移动直连情况，别选移动绕路的段。

**月付还是年付？**
第一次买，月付。哪怕年付折合下来便宜 40%，你也要先确认这批 IP 在你的业务环境里能过。已经跑顺了、确定要长期用，再切年付 + 九折，把成本压到 30 元/月这个区间。

**能解锁 Netflix、Disney+、ChatGPT 吗？**
官方标称支持 TikTok、ChatGPT、Claude、Facebook、WhatsApp、亚马逊、Netflix、Hulu、Disney+、HBO Max、ESPN、Amazon Prime Video 等。但流媒体解锁是动态的，平台随时调整，别把它当成合同条款，到手先测你要的那个。
